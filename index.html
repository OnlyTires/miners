// what is solo mining?

One device. One shot at the whole block.

Bitcoin mining works by having computers compete to solve a cryptographic puzzle. Every ~10 minutes, one miner on the entire planet solves it and wins the full block reward, currently 3.125 BTC, paid directly to their wallet.

Solo mining means you're entering that competition alone, not splitting rewards with a pool. If your device solves the block, you collect the entire reward yourself. If you don't solve it, you receive nothing.

At 350 KH/s against a global network running at hundreds of exahashes per second, the odds are astronomically small, but the chance is always live while the device is running. Every block is a new draw.

Think of it as a lottery ticket that runs 24/7, costs ~$0.11/month in electricity, and displays your NFT on the screen while it works. The device isn't here to make you rich, but it's genuinely participating in the Bitcoin network.

Get mining in minutes

Your device ships pre-flashed and ready. You just need WiFi and a Bitcoin address.

Initial setup

1

Power on via USB-C

Connect to any USB-C charger or port. ~1W draw. Any USB port works. The display lights up automatically.

2

Connect to the setup hotspot

On first boot, the device broadcasts a WiFi access point. Connect to it from your phone or computer. No password required.

A browser portal should open automatically. If it doesn't, open your browser and go to 192.168.4.1.

3

Set up your WiFi network

Enter your home WiFi name (SSID) and password in the portal. Both are case-sensitive. Capitals and special characters must match exactly. Tap Save and the device reboots and joins your network.

4

Add your Bitcoin address

After connecting, enter your BTC wallet address in the portal. This is where any block reward would be sent. See the address format section below for supported formats.

5

Change the portal password (optional)

You can set a password for the configuration portal to prevent unauthorized changes. Leave it blank to keep it open. Recommended if the device is on a shared or public network.

6

Watch it mine

The display shows live hashrate (~350 KH/s), block height, pool connection, and shares submitted. Done. It runs 24/7 unattended.

Physical buttons

The NerdMiner V2 has two physical buttons on the board. Here's what each one does:

BTN
1
Button 1, furthest corner (outer edge)
Soft reset. Press once to restart the device. Reboots the firmware and reconnects to your saved WiFi and pool. No settings are lost.
BTN
2
Button 2, second from corner (inward)
Hard reset + full reconfiguration. Hold for 10 seconds to wipe saved WiFi credentials and relaunch the setup hotspot (NerdMinerAP). Use this if you need to connect to a new network, recover from a bad config, or start fresh. Your Bitcoin address may need to be re-entered after a hard reset.
💡

When to use each button

  • Display frozen or hashrate dropped to 0 → try Button 1 (soft reset) first.
  • Changed WiFi networks or router password → hold Button 2 for 10 seconds to reconfigure.
  • Moving to a new location → hold Button 2, reconnect to NerdMinerAP, enter new WiFi details.
  • Forgot your portal password → hold Button 2 for 10 seconds. This resets the config including the password.
ℹ️

Default pool: pool.sethforprivacy.com

Your device ships pre-configured to pool.sethforprivacy.com, a public solo mining pool built for low-hashrate devices like NerdMiner. Worker count and hashrate stats on the display are confirmed to work correctly with this pool. If you switch pools, these stats may not display accurately. That's a pool compatibility issue, not a hardware fault. The device is still mining either way. We recommend keeping the default pool.

Bitcoin address format

Only standard on-chain Bitcoin addresses work. Use one of these formats:

✓

Native SegWit, starts with bc1q

Modern standard. Example: bc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh. Most wallets (BlueWallet, Sparrow, Exodus) generate these by default.

✓

Legacy, starts with 1

Older format, fully supported. Example: 1A1zP1eP5QGefi2DMPTfTL5SLmv7Divf.

✓

P2SH SegWit, starts with 3

Compatibility format. Example: 3J98t1WpEZ73CNmQviecrnyiWrnqRhWNLy. Works fine.

⚠️

Do NOT use these

  • Lightning Network addresses, off-chain. Pools can't pay to them.
  • Taproot addresses (bc1p), not universally supported by all public pools.
  • Exchange deposit addresses. Many exchanges don't credit mining payouts.
  • Any Ethereum or non-Bitcoin address. These will cause errors.

Troubleshooting

Device won't connect to WiFi

WiFi credentials are case-sensitive. This is the most common issue. Check:

  • SSID (network name) must match exactly. MyNetwork and mynetwork are treated as different networks.
  • Password must match exactly, including capitals, numbers, and symbols.
  • The device only supports 2.4 GHz WiFi. If your router broadcasts 2.4 GHz and 5 GHz under one name, split them or connect to the 2.4 GHz band specifically.
  • Guest networks with captive portals (hotel/café) block mining pool connections. Use a standard home network.

To re-enter credentials: hold the device button for several seconds to reset and relaunch the setup hotspot.

Display shows 0 KH/s or no hashrate
  • Check that WiFi connected (WiFi icon on display).
  • Pool address should be pool.sethforprivacy.com.
  • Some routers/firewalls block mining pool ports. Try on a different network to test.
  • Hashrate can take 30 to 60 seconds to appear after first connecting.
Worker count or stats not displaying correctly

Worker count and pool-side stats are confirmed accurate on the default pool pool.sethforprivacy.com. If you've switched to a different pool, these may show 0 or not update. This is a pool compatibility limitation, not a hardware issue. The device is still mining. Switching back to the default pool restores full stats.

Bitcoin address is being rejected

Make sure your address starts with bc1q, 1, or 3. Common mistakes:

  • Using a Lightning invoice (starts with lnbc). This is not an on-chain address.
  • Using a Taproot address (bc1p). Not supported by all pools.
  • Pasting an Ethereum address (0x…) by mistake.
  • Extra spaces before/after the address when pasting.
Display is frozen or showing garbled graphics

Unplug and replug the USB-C cable to power-cycle. This reboots the firmware cleanly. If garbled graphics persist, the firmware may need reflashing. Instructions and the latest binary are on the NerdMiner V2 GitHub.

How do I change the mining pool?

Connect to the same WiFi network as your device. Find the device's IP address (shown on the display or in your router's device list). Open that IP in a browser. The web interface lets you change the pool URL, port, and BTC address. Worker stats only display correctly on pool.sethforprivacy.com.

What are my actual odds of winning a block?

Very low. To be direct with you: a 1W device running at 350 KH/s against a Bitcoin network operating at hundreds of exahashes per second is not going to print money. The odds of solving a block are astronomically small. We're talking statistical timeframes measured in millions of years for a single device. That is the honest answer and we won't sugarcoat it.

What the device is doing is real. It's submitting valid SHA-256 work to a solo mining pool and every new Bitcoin block gives it a mathematically legitimate (if tiny) chance. That chance is always live while the device runs. This is not a get-rich device. It's a desktop display that happens to participate in something real. The value is in the object, a one-of-a-kind piece built from your NFT that sits on your desk and does something most people have never seen.
